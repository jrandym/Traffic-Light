# Traffic Light
## PRIMM
1. **Predict**: What will you see? What happens when you click each light?Run: Click all three lights. Were you right?
2. Investigate: Find the code that checks a click on the red light. Why can't you get back to green?
3. Modify: Make yellow and green clickable.
4. Make: Drive on green, slow on yellow, stop on red.

5. Bonus: Wrap the car around the screen.
